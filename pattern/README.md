# BETA Pattern

BETA Pattern is the open-source pattern-making and grading software of Project BETA. You draft pattern pieces, grade them into sizes, digitize paper patterns from a photo, and send them to BETA Marker.

**Status: version 0.1 in development (engine first, user interface later).** See [SPEC.md](SPEC.md) and the [cutting-room plan](../marker/docs/CUTTING-ROOM-PLAN.md).

Why we build it: no permissively licensed industrial pattern CAD exists. Seamly2D and Valentina are good open tools, but they are GPL, so their code cannot be part of BETA. BETA Pattern will read their files.
