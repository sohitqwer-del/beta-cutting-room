# BETA Marker academic benchmark

Revision: cdc71595999599dff5eda92bef894a2081feb92e. Dirty worktree: yes. Platform: windows / x86_64.

Machine: Intel Core i9-11900H laptop, 16 logical CPUs. The dirty flag includes Cargo adding missing direct dependency edges (geo/rand) for the nest crate and concurrent documentation/converter audit changes. The Rust benchmark used revision cdc7159.

21 runs; 20 valid. Wall time 674.780 s; summed nesting time 1290.761 s. Parallel tasks: 2; threads per task: 3. Exact seeds and budgets are in run.json.

Reproduce: `cargo run --release -p beta-marker-cli -- bench academic --instances shirts,trousers,swim,albano,dagli,mao,marques --time 60 --seeds 1,2,3 --threads-per-task 3 --jobs 2 --out <fresh-directory>` from `marker/`, with external `CARGO_TARGET_DIR` and `BETA_DATA_DIR` set.

This sample is descriptive: stratum means are unweighted. Published sparrow runs used 1200 s, 3 threads and AMD 7950X hardware (100 runs for the mean); shorter local runs are not hardware-normalized. Lectra software version, hardware and convergence-time semantics are not controlled. Geometry and constraint eligibility must be checked in the converter report. No raw geometry is included in these results.
