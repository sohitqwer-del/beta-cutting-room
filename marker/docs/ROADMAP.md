# Roadmap

This is an order of work, not a delivery schedule. Public release: 0.7.
Development: 0.8. Help us choose priorities with a reproducible example.

## Now: prepare 0.8 for review

- Validate the new paper-set workflow on phone and desktop, including reopened sets and tape-check failures.
- Check Improve area preview/Apply/Undo and open-fabric width/ratio/cost handoff end to end.
- Re-run the public nesting benchmark; keep regressions, wall times and validation failures visible.
- Finish the first-minute sample path, documentation and screenshots; verify the shipped app matches them.
- Retest offline storage, backup/restore, layer counts and all factory exports in release builds.
- Retain the independent validator and explicit useful-yield/surplus warnings.

These features exist in development. See [features](FEATURES.md),
[paper sets](PAPER-PATTERNS-MSME-2026-10-26.md) and
[workflow experiments](WORKFLOW-IMPROVEMENTS-2026-10-25.md).

## Next: earn factory trust

- Run permission-cleared paper-photo trials with measured errors, lighting/curl cases and tape repeatability.
- Trial one real order with trained operators; compare total fabric per accepted garment, not marker percentage alone.
- Improve folded/tube layouts on small odd orders and constrained jobs without relaxing copy or grain rules.
- Measure browser speed, time to first valid layout and Stop recovery across devices and larger jobs.
- Sew samples and review block ease, fit and post-edit seam/spec warnings with pattern masters.
- Test unsigned installers on clean Windows PCs; resolve Windows 10/WebView2 acceptance and consider signing.
- Calibrate actual plotter/cutter profiles and label printer workflows with operators.
- Review Hindi/Tamil with native-speaking cutters and translate new panels.
- Obtain independent server/security review and test backup recovery at a factory.

## Later: investigate with evidence

- Better photo correction and missing-part review; a searchable pattern library.
- Wider DXF/RUL coverage from legally shareable examples and explicit regression tests.
- Better roll/ratio joint planning, stronger area optimization and measured search alternatives.
- Shared revision/approval workflows, user roles and auditable bundle transfers/reversals.
- Site-specific ERP adapters with duplicate, retry and reversal tests.
- Richer measurement/seam tools and report configuration screens.

3D fit and full commercial CAD parity have no committed delivery plan.
Ideas need scope, licence review and evidence before they become promises.

## What has already moved since the audit?

The [0.7 audit](AUDIT-0.7.md) records older failures. Browser exports and
cutting-room work, ply/pass meanings, useful yield, phone Back navigation and
spec-sheet access were addressed in [0.7](RELEASE-0.7.0.md).
Do not treat those old missing-browser rows as today's backlog. Real-photo,
physical fit, hardware, language and independent security checks remain open.
The October experiments improve some selected cases and regress on others;
see the [mixed pilot](NESTING-THREE-IMPROVEMENTS-2026-10-24.md).
