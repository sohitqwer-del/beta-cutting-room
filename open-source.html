Seamly2D and Valentina

Seamly2D and Valentina are good open-source pattern programs under the GPL licence. BETA contains none of their code. BETA Pattern reads a supported subset of their pattern files so that you can bring existing work across. Any fixes we offer to Seamly2D are sent to that project under its own licence.

Contribute

Report a problem

Tell us what you did, what you expected and what happened. Attach a small test file that you are allowed to share. Never attach a buyer’s pattern without permission.

Improve the code

Open an issue, then a focused pull request with tests. Computing parts are in Rust; screens are in TypeScript. Read CONTRIBUTING.md first.

Improve the benchmark

Run it on your hardware and send the summary files. Better nesting must win on held-out tasks, with every layout valid.

Source code: https://github.com/sohitqwer-del/beta-cutting-room (external site)

Contact

Questions, factory trials and sample markers: sohitqwer@gmail.com.

BETA Cutting Room is a fun project, built with the help of modern AI tools. Every marker is still checked by an independent validator, and every claim on this site comes with its source.

BETA is young and not perfect yet. We need your help to improve it. A short note is enough.
