Self-hosting

Install and self-host

BETA Cutting Room runs on computers you control. Install the desktop app on a Windows PC, or run the server on your own machine. No account, no cloud and no internet connection are needed for daily work.

Try it in your browser

Open the app in your browser

Best for trying and small jobs; for big markers use the desktop app

Windows desktop app

  1. Download the installer

    File: BETA-Cutting-Room_0.7.0_x64-setup.exe (11.08 MiB).

    Download for Windows

  2. Check the file (recommended)

    Open PowerShell in your Downloads folder and run:

    Get-FileHash -Algorithm SHA256 '.\BETA-Cutting-Room_0.7.0_x64-setup.exe'

    The result must match the published checksum: 07e3e7e49332b3554555df46855498d08ed59126e48b17ff3f9348014ae7233e.

  3. Run the installer

    It installs for your Windows user only, so you do not need administrator rights. The installer is not code-signed yet, so Windows SmartScreen may warn you. If the checksum matches, choose More info, then Run anyway.

  4. Check WebView2 (Windows 10 only)

    The app uses Microsoft’s WebView2 runtime to draw its screens. Windows 11 already has it. Most Windows 10 PCs have it too. If the app does not open on Windows 10, install the WebView2 Runtime, Evergreen Standalone Installer from Microsoft. You can copy that installer to the factory PC on a USB drive; the BETA installer never downloads anything.

  5. Start working

    Open BETA Cutting Room from the Start menu. Open a DXF pattern or a project and go from Pattern to Bundles. Projects (.betaproj) save automatically every few seconds and can be recovered after a crash.

Uninstall

Windows Settings → Apps → Installed apps → BETA Cutting Room → Uninstall. Your project files stay where you saved them.

Updates

Install the new version over the old one. Copy it by USB if the PC has no internet.

Portable ZIP (no installation)

The portable package runs the same app in your web browser, without installing anything. It suits a PC where you cannot install programs.

  1. Download BETA-Cutting-Room_0.7.0_windows-x64-portable.zip (12.85 MiB). Download portable ZIP
  2. Check the file: Get-FileHash -Algorithm SHA256 '.\BETA-Cutting-Room_0.7.0_windows-x64-portable.zip'. The result must be ffb220923617fa9e0a5f590ddb71e84bd4b8d438d535dac33bc5bfecb4159eee.
  3. Extract the ZIP to a folder you can write to, for example in Documents.
  4. Run start-server.cmd, then open http://127.0.0.1:7878 in your browser. Leave the console window open; Ctrl+C stops it.

Browser drafts belong to the browser profile. Export your work before you clear browser data.

Server: beta-marker serve

The beta-marker command runs nesting, checks and exports, and can serve the full app to a web browser. Use it on a Linux or Windows machine where you prefer a browser to the desktop app, or for batch work and benchmarks.

Factory network: by default the server listens only on the same computer (address 127.0.0.1). To let other factory PCs connect, start it with --bind and an access token (--token or BETA_TOKEN); it will not start on the network without one. The server has no HTTPS of its own, so put it behind Caddy or nginx and a firewall. Never expose the server to the internet. See marker/docs/SELF-HOSTING.md.

Linux archive SHA-256: d5b3e98d9298b33eaa7b7906058baaff4410d80b7d924735a63a62882030368b.

Build from source

A ready-made Linux server download is available on the download section. It targets x86_64 Linux with glibc 2.31 or newer. The release was checked with extracted Ubuntu glibc 2.31 and with glibc 2.43. On other systems, build it from the source code. You need Rust (with the wasm32-unknown-unknown target and a matching wasm-bindgen tool) and Node.js.

# From the repository root: install and build the web app
npm install
npm run build:wasm -w @beta/marker-wasm
npm run build:pattern-wasm -w @beta/marker-wasm
npm run build -w @beta/marker-web

# From marker/: build and start the server
cargo build --release -p beta-marker-cli
cargo run --release -p beta-marker-cli -- serve --port 7878

Open the address the server prints (for example http://127.0.0.1:7878) in a browser on the same computer. Stop it with Ctrl+C. Full details: marker/apps/web/README.md.

Command-line work

Run beta-marker --help to see every command: import, nest, validate, export, plan, roll, cutroom, batch and bench. Each command also has its own --help.

Privacy

  • Your patterns, markers, orders and roll data stay on your computers. BETA has no cloud service.
  • The app does not send usage data, crash reports or files anywhere. There is no tracking and no account.
  • The server listens only on the computer it runs on.
  • Files you export (PLT, PDF, CSV, Excel) go only where you save them.
  • This website has no trackers or cookies and loads nothing from other servers.

If you send us sample markers for a comparison, we keep them private and never publish them without your written permission.

Offline use

Everything the app needs is inside the installer: screens, help, fonts and the Rust engine. Daily work needs no internet connection. You can install and update from a USB drive. Help pages are included, and this website also works when opened from a folder on disk.

For the WebView2 runtime on Windows 10, see Microsoft’s WebView2 page (external site).
